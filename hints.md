# Offline workbench

Run commands from this workspace. `python3 -B` avoids cache files. `python3 -B -m unittest discover -s tests -p 'test_*.py' -v` discovers the checks. `python3 -B -m json.tool fixtures/ledger.json` formats a fixture. `python3 -B -m dispatch_cli --help` lists commands.

A pure function returns a new value while keeping its input unchanged. `copy.deepcopy` is available if nested values must be changed. Python treats `True` as an integer subclass; strict integer fields use `type(value) is int`. JSON `null` becomes Python `None`, which differs from zero.

A dictionary can index related observations by a composite tuple. For a deterministic cost check, count examined rows rather than elapsed seconds; a counted iterable can increment a counter every time its iterator yields an item. Keep examples small. Use the documented CLI or public Python functions to compare outcomes. Add regression checks for an ordinary case and a nearby boundary. A passing example proves only what that example covers.

Atomic replacement means writing a complete temporary file beside its destination, then replacing the destination. It is not a substitute for multi-process locking. There is no live worker here, so remote delivery, authentication and real cancellation are outside what local evidence establishes.

## Check a local proposal

Run a command against a copied fixture and a separate temporary output path. Parse the output JSON and compare input bytes before/after. Repeat with the first proposal as the new input to check whether a second request adds anything. For failure cases, place recognizable text in the destination beforehand and check it remains unchanged. Python `copy.deepcopy` helps create independent nested data, while selecting an identity can require more than one field. These methods are local; no worker needs to be started.
